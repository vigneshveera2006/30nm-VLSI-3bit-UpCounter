# 30nm VLSI 3-Bit Up Counter Design using TCAD and Cadence Virtuoso

## Project Overview

This project focuses on the design and implementation of a 3-bit up counter using custom-designed 30nm NMOS and PMOS transistors.

The MOSFET devices were first modeled and analyzed using TCAD tools. The extracted device characteristics were then implemented in Cadence Virtuoso for digital circuit design and simulation.

The project provided practical exposure to:
- Semiconductor device modeling
- CMOS inverter and logic design
- Digital VLSI design flow
- Counter implementation using CMOS logic

---

## Objectives

- Design 30nm NMOS and PMOS devices using TCAD
- Analyze device characteristics
- Extract transistor behavior into Cadence Virtuoso
- Build CMOS logic circuits
- Implement a functional 3-bit up counter
- Verify counter operation through simulation waveforms

---

## Project Flow

1. Design of 30nm NMOS transistor in TCAD
2. Design of 30nm PMOS transistor in TCAD
3. Extraction of device parameters
4. Import/implementation in Cadence Virtuoso
5. CMOS logic gate construction
6. Sequential circuit development
7. 3-bit up counter implementation
8. Simulation and waveform verification
